Unified Inventory System (UIS)

About this Project

A system for managing inventory and orders in a warehouse.

Features

  • Manage inventory items (add, update, delete)
  • Manage orders (add, update, delete)
  • Track orders and their statuses
  • Multiple permission levels allows for selective access
